Lo que tratamos de hacer en este trabajo es que sea facil de entender y que el usuario no tenga tantos errores y  por si pasa algun error se previnio con ciertas funciones es un proyecto simple pero que cumple su funcion como juego de estrategia desarrollado en C#
Un trabajo que a base de prueba y error cumple con los requerimientos establecidos en este proyecto
En ciertos momentos se dificulto el proyecto por ejemplo para mover las piezas se utilizo varios lineas de codigo con matrices y funciones que eran requeridas en el juego
El menu del juego se nos presenta un espacio en el que el usuario debe ingresar una contraseña para poder entrar al menu del juego
En el menu del juego se encuentran 4 opciones 
La primera es de iniciar el juego
la segunda es la de ver reglas del juego una opcion muy importante para jugadores nuevos
la tercera es la opcion de ver puntajes 
La ultima opcion es la de salir es decir terminar el juego
